디자인 가이드

모든 새 페이지는 assets/ds.css 한 장만 불러오면 같은 색·버튼·카드·표를 씁니다. 이 페이지가 그 규칙의 원본이에요.

공통 vs 개별 무엇을 맞추고 무엇을 자유롭게 둘지

반드시 공통

  • 색 토큰 · 라이트/다크
  • 버튼 · 칩 · 태그 · 입력창
  • 상단바(← 모음집 / 테마)
  • 44px 터치 높이, 포커스 링
  • 표 → 모바일 카드 전환

페이지 성격별 템플릿

  • 목록형 — 모음집 (그룹 + 카드 전체 탭)
  • 문서형 — 구조도 (긴 글, 목차)
  • 대시보드형 — 브리핑·클라이언트 (통계 + 표)

개별 자유

  • 입시 레이더 · 답모아 · 국제관계 · VOID Cards 같은 독립 서비스는 자기 개성(브랜드 색, 레이아웃)을 유지
  • 단, 모음집 카드와 “← 모음집” 링크만 공통

색 브랜드 색은 하나, 나머지는 중립

--bg 바탕
--surface 카드
--ink 글자
--muted 보조
--brand 강조
--ok 정상
--warn 주의
--bad 위험

버튼 한 영역에 주 버튼은 하나

  • 라벨은 동사만: 열기, 다운로드, 저장. “~ 열기”처럼 대상 이름을 반복하지 않음 (대상은 카드 제목이 말해줌)
  • 나란히 놓이는 버튼은 btn-fixed로 너비를 맞춤. 외부 링크는 ↗를 붙임
  • 파괴적 동작은 btn-danger, 되돌릴 수 없으면 확인 한 번 더
  • 모바일에서 손가락 크기: 최소 44px(--tap). 작은 버튼(btn-sm)은 보조 링크에만
